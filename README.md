## 在线访问
- 分享链接（GitHub Pages，永久稳定、自动同步）：`https://xuanxuan-12345678.github.io/kaoyan-tracker/`

## 文件说明
- `index.html`：单文件仪表盘，零外链、数据本地优先 + 远程 `data.json` 实时同步
- `data.json`：实时数据源，由每日自动化从各院校官方招生网采集后推送更新

## 数据来源与说明
- 权威源：研招网、各院校研究生招生网/研究生院官网、医学院官网、省教育考试院
- 状态含义：已发布 / 参考2026（仅公布 2026，2027 以官方为准）/ 需人工确认（官方简章为 PDF 等无法自动解析）/ 待官方更新
- 所有数字均附官方原文链接；未找到则标「待官方更新」，禁止编造
- 学科评估采用教育部第四轮（2016）官方结果，仅供参考

> 本仓库为公开仓库，`data.json` 全网可读，但仅含各院校公开招生信息，无个人隐私。
